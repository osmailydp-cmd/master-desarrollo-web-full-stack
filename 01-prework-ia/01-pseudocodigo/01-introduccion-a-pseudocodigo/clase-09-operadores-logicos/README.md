## Contenido de la clase

Introducción a los operadores relacionales y lógicos en PSeInt, utilizados para comparar valores y combinar condiciones que producen resultados verdaderos o falsos.

**Conceptos estudiados:**
- Operadores relacionales: `>`, `<`, `>=`, `<=` e igualdad.
- Variables de tipo lógico.
- Evaluación de expresiones verdaderas o falsas.
- Operador lógico `Y` para combinar condiciones.
- Operador lógico `O` para evaluar condiciones alternativas.
- Aplicación de condiciones mediante estructuras `Si...SiNo`.
