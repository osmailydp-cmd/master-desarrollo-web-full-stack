## Ejercicio 01 — Presentación personal

**Archivo:** [dia06_ejercicio01_presentacion_personal.psc](./dia06_ejercicio01_presentacion_personal.psc)

**Objetivo:** Crear un programa que solicite el nombre y la ciudad de un usuario para mostrar un mensaje personalizado.

**Descripción:** El algoritmo declara dos variables de tipo carácter, captura los datos introducidos por el usuario y construye un saludo utilizando ambos valores.

**Conceptos aplicados:** Variables de tipo carácter, entrada y salida de datos, `Leer`, `Escribir`, `Escribir Sin Saltar` y concatenación de texto.

## Ejercicio 02 — Información del alumno

**Archivo:** [dia06_ejercicio02_informacion_alumno.psc](./dia06_ejercicio02_informacion_alumno.psc)

**Objetivo:** Solicitar el nombre, la edad y el curso de un alumno para generar un mensaje personalizado.

**Descripción:** El algoritmo utiliza variables de tipo carácter y entero, solicita los datos del alumno y muestra una frase combinando texto con los valores almacenados.

**Conceptos aplicados:** Declaración de variables, tipos de datos, entrada de información, salida formateada y concatenación.

## Ejercicio 03 — Tarjeta de usuario

**Archivo:** [dia06_ejercicio03_tarjeta_usuario.psc](./dia06_ejercicio03_tarjeta_usuario.psc)

**Objetivo:** Crear un programa que solicite los datos personales de un usuario y los presente en un perfil organizado.

**Descripción:** El algoritmo captura el nombre, la ciudad, la edad y la profesión mediante variables de tipo carácter y entero. Posteriormente, muestra toda la información en formato de ficha personal.

**Conceptos aplicados:** Declaración de múltiples variables, tipos de datos, entrada y salida de información y presentación estructurada de resultados.
