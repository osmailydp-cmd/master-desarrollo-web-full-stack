# Ejercicios — Clase 04

**Clase:** AP S21 - Día 3 - ¿Cómo piensan los programadores?  
**Lenguaje:** Pseudocódigo  
**Herramienta:** PSeInt

## Ejercicio 01 — Semáforo

**Archivo:** [Seudocodigo_Día3_semaforo.psc](./Seudocodigo_Día3_semaforo.psc)


**Objetivo:** Determinar si un peatón puede cruzar una calle según el estado de un semáforo.

**Descripción:** El algoritmo solicita el color del semáforo. Si es verde, permite cruzar. Si es rojo, indica que el peatón debe esperar y solicita nuevamente el color hasta que sea verde.

**Conceptos aplicados:** Variables, condicionales, ciclos y entrada/salida de datos.

## Ejercicio 02 — Cajero automático

**Archivo:** [Seudocodigo_Día3_cajeroAutomatico.psc](./Seudocodigo_Día3_cajeroAutomatico.psc)

**Objetivo:** Simular una operación de extracción de dinero mediante una tarjeta bancaria.

**Descripción:** El algoritmo verifica la presencia de la tarjeta, valida el código ingresado y comprueba que el monto solicitado no supere el saldo disponible.

**Conceptos aplicados:** Variables lógicas y enteras, condicionales anidados, operadores de comparación y validación de datos.
