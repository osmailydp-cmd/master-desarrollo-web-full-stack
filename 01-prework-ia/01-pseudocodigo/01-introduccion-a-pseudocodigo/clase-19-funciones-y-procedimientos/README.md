# Clase 19 - Funciones y procedimientos

**Curso:** Máster en Desarrollo Web Full Stack  
**Categoría:** Prework + IA  
**Módulo:** Pseudocódigo  
**Tema:** Introducción a Pseudocódigo

## Contenido de la clase

Introducción a las funciones y procedimientos como herramientas para organizar y reutilizar código en PSeInt.

Se estudian los siguientes conceptos:

- Procedimientos o subprocesos.
- Funciones con valores de retorno.
- Parámetros y argumentos.
- Diferencias entre funciones y procedimientos.
- Reutilización de código y programación modular.

Durante la clase se presentan ejemplos prácticos de saludos, cálculos matemáticos, comparaciones y tablas de multiplicar.

## Documentación

En la carpeta [documentacion](documentacion/README.md) se encuentra el resumen teórico de la clase, con explicaciones y ejemplos de PSeInt sobre funciones, procedimientos, parámetros y valores de retorno.

Los ejemplos desarrollados durante la clase están recogidos como material de estudio y no se incluyen ejercicios prácticos independientes.
