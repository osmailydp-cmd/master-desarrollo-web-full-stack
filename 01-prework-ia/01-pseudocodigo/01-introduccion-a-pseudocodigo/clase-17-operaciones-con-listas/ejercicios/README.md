## Reto — Buscar la posición de un valor

**Archivo:** [dia16_ejercicio_reto_posicion_de_valor_buscado.psc](./dia16_ejercicio_reto_posicion_de_valor_buscado.psc)

**Objetivo:** Buscar un número dentro de una lista de cinco elementos e indicar la posición donde se encuentra.

**Descripción:** El algoritmo solicita cinco números y los almacena en un array unidimensional. Posteriormente, pide un valor para buscarlo y recorre la lista mediante un bucle `Mientras` hasta encontrar la primera coincidencia o finalizar el recorrido.

Si encuentra el valor, muestra su posición utilizando índices desde cero. En caso contrario, informa que el número no existe en la lista.

**Conceptos aplicados:** Arrays unidimensionales, índices, búsqueda secuencial, bucles `Mientras`, variables lógicas, operadores de comparación y condiciones de terminación.

---

## Observaciones

Este reto permitió practicar la búsqueda de elementos dentro de una lista, utilizando una variable lógica para controlar cuándo detener el recorrido.

El algoritmo conserva la primera coincidencia encontrada y finaliza la búsqueda sin recorrer innecesariamente los elementos restantes.
