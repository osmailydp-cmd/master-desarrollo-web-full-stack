## Ejercicio 01 — Array de 3 números

**Archivo:** [dia14_ejercicio01_array_de_3_numeros.psc](./dia14_ejercicio01_array_de_3_numeros.psc)

**Objetivo:** Crear un array de tres números y mostrar sus elementos.

**Descripción:** El algoritmo solicita tres valores, los almacena en un array unidimensional y posteriormente recorre sus posiciones para mostrarlos.

**Conceptos aplicados:** Arrays unidimensionales, declaración y dimensionamiento, índices y bucles `Mientras`.

## Ejercicio 02 — Array de 5 edades

**Archivo:** [dia14_ejercicio02_array_de_5_edades.psc](./dia14_ejercicio02_array_de_5_edades.psc)

**Objetivo:** Almacenar y mostrar cinco edades utilizando un array.

**Descripción:** El algoritmo solicita cinco edades, las guarda en un array de enteros y luego muestra todos los valores almacenados.

**Conceptos aplicados:** Arrays, variables enteras, índices y recorrido de estructuras de datos.

## Ejercicio 03 — Sumar números de una lista

**Archivo:** [dia14_ejercicio03_sumar_5_numeros_de_una_lista.psc](./dia14_ejercicio03_sumar_5_numeros_de_una_lista.psc)

**Objetivo:** Calcular la suma de cinco números almacenados en un array.

**Descripción:** El algoritmo carga cinco números en un array y utiliza un segundo recorrido para acumular sus valores y mostrar la suma total.

**Conceptos aplicados:** Arrays unidimensionales, bucles, acumuladores y operaciones aritméticas.

## Ejercicio 04 — Encontrar el número mayor

**Archivo:** [dia14_ejercicio04_mostrar_el_mayor_de_5_numeros.psc](./dia14_ejercicio04_mostrar_el_mayor_de_5_numeros.psc)

**Objetivo:** Identificar el número mayor entre cinco valores almacenados.

**Descripción:** El algoritmo almacena cinco números y los recorre comparándolos con una variable inicializada con el primer elemento del array.

**Conceptos aplicados:** Arrays, operadores relacionales, estructuras condicionales y búsqueda del valor máximo.

## Ejercicio 05 — Contar aprobados

**Archivo:** [dia14_ejercicio05_contar_aprobados_de_una_lista.psc](./dia14_ejercicio05_contar_aprobados_de_una_lista.psc)

**Objetivo:** Contar cuántas de cinco notas están aprobadas.

**Descripción:** El algoritmo solicita cinco notas, las almacena en un array e incrementa un contador por cada nota igual o superior a cinco.

**Conceptos aplicados:** Arrays, contadores, condiciones y operadores relacionales.

## Ejercicio 06 — Tabla de multiplicar

**Archivo:** [dia14_ejercicio06_tabla_multiplicar.psc](./dia14_ejercicio06_tabla_multiplicar.psc)

**Objetivo:** Mostrar la tabla de multiplicar del 1 al 10 de un número introducido.

**Descripción:** El algoritmo solicita un número y utiliza un bucle `Mientras` para calcular y mostrar sus diez multiplicaciones.

**Conceptos aplicados:** Bucles, contadores, multiplicación y presentación formateada de resultados.

---

## Observaciones

Estos ejercicios permitieron practicar la declaración, carga y recorrido de arrays unidimensionales, así como su combinación con acumuladores, contadores y estructuras condicionales.

El ejercicio 06 refuerza el uso de bucles y operaciones aritméticas sin requerir un array.

Los algoritmos se conservan como parte de mi proceso de aprendizaje con PSeInt.
