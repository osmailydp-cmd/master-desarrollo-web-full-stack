**Estado:** Finalizado

## Contenido de la clase

Introducción al concepto de variables en programación utilizando PSeInt, aprendiendo a declarar, almacenar y utilizar diferentes tipos de datos dentro de un algoritmo.

**Conceptos estudiados:**
- Declaración y utilización de variables.
- Tipos de datos: carácter, entero y real.
- Almacenamiento de información en variables.
- Entrada de datos mediante `Leer`.
- Salida de información mediante `Escribir` y `Escribir Sin Saltar`.
- Combinación de textos y variables para mostrar resultados personalizados.
