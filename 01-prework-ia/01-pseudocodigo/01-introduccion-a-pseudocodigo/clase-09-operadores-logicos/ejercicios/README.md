## Ejercicio 01 — Mayor de edad

**Archivo:** [dia08_ejercicio01_mayor_edad.psc](./dia08_ejercicio01_mayor_edad.psc)

**Objetivo:** Solicitar la edad del usuario y evaluar si es mayor o igual a 18 años.

**Descripción:** El algoritmo almacena la edad introducida y evalúa la expresión relacional `edad >= 18`, guardando y mostrando el resultado lógico.

**Conceptos aplicados:** Variables enteras y lógicas, operadores relacionales, comparación de valores y entrada y salida de datos.

## Ejercicio 02 — Número entre 10 y 20

**Archivo:** [dia08_ejercicio02_numero_entre_10_y_20.psc](./dia08_ejercicio02_numero_entre_10_y_20.psc)

**Objetivo:** Comprobar si un número se encuentra entre 10 y 20, incluyendo ambos límites.

**Descripción:** El algoritmo solicita un número y utiliza el operador lógico `Y` para verificar que cumpla simultáneamente las condiciones `numero >= 10` y `numero <= 20`. Muestra el resultado de la evaluación.

**Conceptos aplicados:** Operadores relacionales, operador lógico `Y`, variables lógicas y estructuras condicionales.

## Ejercicio 03 — Nota y recuperación

**Archivo:** [dia08_ejercicio03_nota_recuperacion.psc](./dia08_ejercicio03_nota_recuperacion.psc)

**Objetivo:** Evaluar si un alumno tiene una nota igual o superior a 5 o si ha realizado recuperación.

**Descripción:** El algoritmo solicita la nota del alumno y si realizó recuperación. Posteriormente, evalúa ambas condiciones utilizando el operador lógico `O` y muestra el resultado.

**Conceptos aplicados:** Variables reales, de carácter y lógicas, operadores relacionales y operador lógico `O`.
