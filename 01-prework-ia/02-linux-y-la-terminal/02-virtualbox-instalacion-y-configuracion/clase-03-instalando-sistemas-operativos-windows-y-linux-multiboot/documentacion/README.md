## 1. Objetivo de la clase

Conocer los aspectos relacionados con la preparación e instalación de sistemas operativos Windows y Linux, así como las herramientas y los escenarios que deben considerarse durante estos procesos.

La presentación de la clase establece seis apartados que servirán como estructura para organizar los apuntes.
