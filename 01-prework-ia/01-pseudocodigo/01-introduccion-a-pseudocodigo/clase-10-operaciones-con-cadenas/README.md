## Contenido de la clase

Introducción a las operaciones con cadenas de texto en PSeInt, utilizando funciones para obtener información de una cadena y combinar diferentes textos en un mismo resultado.

**Conceptos estudiados:**
- Variables de tipo carácter.
- Manejo de cadenas de texto.
- Función `Longitud()` para calcular el número de caracteres.
- Función `Concatenar()` para unir cadenas.
- Construcción de mensajes mediante variables auxiliares.
- Entrada y salida de información textual.
