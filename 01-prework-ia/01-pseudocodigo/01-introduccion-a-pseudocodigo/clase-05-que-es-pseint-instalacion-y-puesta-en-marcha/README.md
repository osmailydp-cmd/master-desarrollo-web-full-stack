# Clase 05 - ¿Qué es PSeInt?

**Curso:** Máster en Desarrollo Web Full Stack  
**Categoría:** Prework + IA  
**Módulo:** Pseudocódigo  
**Tema:** Introducción a Pseudocódigo

## Contenido de la clase

Introducción a PSeInt como herramienta educativa para desarrollar y ejecutar algoritmos en pseudocódigo.

Se estudian sus principales funcionalidades, el proceso de instalación en diferentes sistemas operativos y la configuración del perfil utilizado durante el curso.

## Documentación

En la carpeta [documentacion](documentacion/README.md) se encuentra el resumen teórico de la clase, incluyendo la instalación de PSeInt, sus funcionalidades y las principales opciones de configuración.
