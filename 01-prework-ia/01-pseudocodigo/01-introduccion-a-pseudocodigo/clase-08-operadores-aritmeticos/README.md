## Contenido de la clase

Introducción al uso de operadores aritméticos en PSeInt para realizar cálculos matemáticos utilizando variables numéricas.

**Conceptos estudiados:**
- Operadores de suma (`+`), resta (`-`), multiplicación (`*`) y división (`/`).
- Variables numéricas de tipo entero y real.
- Operaciones matemáticas y expresiones con paréntesis.
- Entrada de datos y presentación de resultados.
- Aplicación de operaciones aritméticas a problemas prácticos.

## Ejercicios realizados

| Nº | Ejercicio | Descripción |

| 02 | Media de tres números | Calcular la media aritmética de tres valores. |
