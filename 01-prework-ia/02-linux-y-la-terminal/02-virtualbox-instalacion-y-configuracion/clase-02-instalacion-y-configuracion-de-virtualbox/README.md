# Clase 02 — Instalación y configuración de VirtualBox

**Curso:** Máster en Desarrollo Web Full Stack  
**Categoría:** Prework + IA  
**Módulo:** Linux y la Terminal  
**Tema 02:** VirtualBox, instalación y configuración

## Contenido de la clase

Introducción a VirtualBox, sus principales funcionalidades y las opciones disponibles para preparar una máquina virtual.

Los contenidos incluyen:

- Descarga e instalación de VirtualBox.
- Conceptos fundamentales de virtualización.
- Reconocimiento de la interfaz de usuario.
- Imágenes ISO y discos virtuales.
- Preparación de una primera máquina virtual.
- Recursos de apoyo para solucionar errores habituales de instalación.
