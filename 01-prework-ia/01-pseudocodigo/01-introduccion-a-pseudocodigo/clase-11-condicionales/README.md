## Contenido de la clase

Introducción a las estructuras condicionales en PSeInt, utilizadas para controlar el flujo de ejecución de los algoritmos mediante la evaluación de condiciones lógicas.

**Conceptos estudiados:**
- Estructuras condicionales `Si...Entonces...SiNo...FinSi`.
- Condicionales simples y anidados.
- Operadores relacionales para comparar valores.
- Operadores lógicos `Y` y `No`.
- Evaluación de condiciones verdaderas y falsas.
- Clasificación de valores mediante rangos numéricos.
- Toma de decisiones según los datos introducidos.
