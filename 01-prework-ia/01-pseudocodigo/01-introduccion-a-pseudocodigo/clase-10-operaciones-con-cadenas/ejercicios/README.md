## Ejercicio 01 — Longitud del nombre

**Archivo:** [dia09_ejercicio01_longitud_del_nombre.psc](./dia09_ejercicio01_longitud_del_nombre.psc)

**Objetivo:** Solicitar el nombre del usuario y mostrar la cantidad de caracteres que contiene.

**Descripción:** El algoritmo captura el nombre introducido, utiliza la función `Longitud()` para calcular su longitud y muestra el resultado.

**Conceptos aplicados:** Variables de tipo carácter y entero, función `Longitud()`, entrada y salida de datos y operaciones con cadenas.

## Ejercicio 02 — Nombre y ciudad

**Archivo:** [dia09_ejercicio02_nombre_ciudad.psc](./dia09_ejercicio02_nombre_ciudad.psc)

**Objetivo:** Solicitar el nombre y la ciudad del usuario para construir un mensaje personalizado.

**Descripción:** El algoritmo captura ambos datos y utiliza la función `Concatenar()` para construir progresivamente un mensaje mediante una variable auxiliar. También conserva como comentario una alternativa de salida directa utilizando `Escribir`.

**Conceptos aplicados:** Variables de tipo carácter, función `Concatenar()`, concatenación de cadenas, entrada y salida de datos y construcción de mensajes.
